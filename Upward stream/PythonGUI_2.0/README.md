# ПОТОК · Наземная станция LoRa

Интерфейс управления планером на Python и Tkinter. Тёмная тема с бирюзовыми
акцентами, показатели телеметрии, отдельные вкладки управления и настроек.

## Запуск

Нужен Python 3.10+ с Tkinter (рекомендуется стандартная сборка Tk 8.6+).
На Windows Tkinter обычно входит в установщик Python. В Linux установите
пакет `python3-tk` через пакетный менеджер вашей системы.

Из каталога `Upward stream/PythonGUI`:

```bash
python -m pip install -r requirements.txt
python gui.py
```

`requirements.txt` содержит зависимости наземной станции. Утилита
`plot_lora.py` по-прежнему требует отдельной установки `pandas` и `matplotlib`.

## Работа с интерфейсом

- В боковой панели выберите порт и нажмите **Подключить**. Скорость — 115200 бод.
  Обновление списка сохраняет выбранный порт, если он всё ещё доступен.
- **Обзор**: высота, температура, освещённость, номер борта, три оси IMU,
  график последних 120 значений высоты и переключение режимов полёта.
- **Управление**: два сервопривода, раскрытие крыльев, ручное управление
  мотором рысканья и временные целевые углы.
- **Датчики и PID**: калибровка, коэффициенты PID с сохранением на SD-карту
  борта и повторная инициализация модулей.
- **Журнал событий**: сообщения борта, команды и ошибки с временными метками.
  Кнопка **Очистить** очищает только экран. Полный файл записи сохраняется.

График использует только принятые данные; горизонтальная ось показывает порядок
пакетов, а не равномерное время. После отключения последние показатели остаются
на экране с пометкой об отсутствии связи. Новое подключение очищает показатели
и очередь предыдущей сессии. При отсутствии пакетов более трёх секунд появляется
индикатор устаревшей телеметрии. Статус порта сам по себе не подтверждает радиосвязь.

Окно изменяет размер; содержимое вкладок прокручивается на небольшом экране.
Вкладки можно переключать через `Ctrl+Tab`, а поля и кнопки — клавишей `Tab`.
Команды с клавиатуры работают так же, как с мышью.

Запись `telemetry_YYYYMMDD_HHMMSS.txt` создаётся в текущем рабочем каталоге при
подключении. Формат строк совместим с существующим `plot_lora.py`.

## Совместимость команд

Сохранены исходные команды `CMD <id> <param>`, значения параметров,
приоритет команды остановки и отправка очереди при обработке сообщений.
Режим полёта меняется на экране после получения телеметрии, а не по нажатию кнопки.
Остановка мотора остаётся приоритетной командой в очереди, а не отдельным
каналом аварийного отключения.

Геймпад: A — GLIDE, B — RECOVERY, Y — раскрытие крыльев, X — остановка;
назначения стиков, мёртвая зона и ограничения мотора сохранены. Геймпад
определяется при запуске. Для подключения нового устройства перезапустите GUI.

## Проверки

```bash
python -m unittest discover -s tests -v
```

Тесты используют реальные виджеты Tkinter и последовательный порт `loop://`.
Они не отправляют команды оборудованию. Для Linux без дисплея:

```bash
xvfb-run -a python -m unittest discover -s tests -v
```

Проверяются привязки команд, разбор телеметрии, очистка журнала и сохранение
выбранного порта. Проверка с физическим LoRa-модулем и геймпадом выполняется
отдельно на оборудовании.

## Файлы

- `gui.py` — подключение, телеметрия, журнал и команды.
- `dashboard.py` — компоновка и элементы управления.
- `theme.py` — тема, прокручиваемая страница и график высоты.

Все три файла должны находиться рядом. `gamepad.py` и `plot_lora.py` —
существующие самостоятельные утилиты; их код не изменён.
