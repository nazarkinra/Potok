# Проект LoRa278 (копия)

Этот проект предназначен для микроконтроллера STM32F401CCU6. Это вариант комплексного проекта, использующий модуль LoRa для связи вместе с несколькими датчиками, включая HMC5883L (компас), BMP280 (давление/температура) и MPU6050 (акселерометр/гироскоп). В отличие от основной версии проекта, в этой копии не используется контроллер PCA9685 для управления моторами.
